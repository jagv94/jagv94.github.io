# Copywriting JA

## Scope

Japanese copy is currently split between:

- `data/strings.json`
  - shared UI
  - hero
  - contact
  - timeline
- `data/projects.js`
  - featured project copy
  - archive summaries
  - contribution bullets

## Positioning

The Japanese locale keeps the same positioning as the rest of the site:

- `テクニカルゲームデザイナー`
- `ゲームプレイシステム`
- `VR/XR`
- implementation, iteration and player-experience clarity

## Key visible strings

- Hero subtitle: `テクニカルゲームデザイナー | ゲームプレイシステム & VR/XR`
- Archive bridge: `追加のプロジェクト、プロトタイプ、ゲームジャム作品は下のアーカイブで確認できます。`
- Contact section frames opportunities around `テクニカルゲームデザイナー`, not a generic designer label.

## Project voice

### Featured

- case-study tone
- deeper systemic explanation
- explicit contribution bullets

### Archive

- short game summary first
- personal contributions second
- CTA last
