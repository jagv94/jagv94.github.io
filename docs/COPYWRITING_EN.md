# Copywriting EN

## Scope

English copy is now split between:

- `data/strings.json`
  - shared UI
  - hero
  - contact
  - timeline
- `data/projects.js`
  - featured project copy
  - archive summaries
  - contribution bullets

## Positioning

Core pitch:

- `Technical Game Designer`
- focus on `Gameplay Systems`
- focus on `VR/XR`
- emphasis on implementation capability, iteration and player-facing clarity

## Key visible strings

- Hero subtitle: `Technical Game Designer | Gameplay Systems & VR/XR`
- Archive bridge: `Additional projects, prototypes and game jam work can be found in the archive below.`
- Contact CTA framing: opportunities are described as `Technical Game Designer` roles, not generic `Game Designer` roles.
